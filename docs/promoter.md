# Памятка промоутеру

1. Откройте личный чат бота и нажмите `/start`. Если доступа нет — отправьте свой `/id` владельцу. В группе анкета не работает.
2. Нажмите «Добавить лида». Введите имя родителя и один контакт: телефон или Telegram @username/ссылку. Второй контакт можно добавить. Проверка телефона проверяет формат, а не принадлежность номера.
3. Для телефона отметьте известные мессенджеры. Если не спросили — «Только телефон / не указано». Выберите предпочтение связи кнопкой. Без телефона звонки недоступны.
4. Введите имя и возраст ребёнка. Если возраст неизвестен — «Не уточнили». Добавьте остальных детей кнопкой «Добавить ребёнка»: это останется одной семейной заявкой.
5. Можно добавить один комментарий или пропустить. Пишите как сказали родители, включая «через две недели», «после 19:00», «нельзя сладкое». Даты и смысл бот не пересказывает.
6. Проверьте все ответы. «Исправить» позволяет изменить контакты, конкретного ребёнка, добавить/удалить ребёнка, изменить/удалить комментарий. В семье остаётся минимум один ребёнок. Если заголовок длиннее лимита CRM, бот попросит ввести понятное сокращение; полные имена сохраняются в примечании.
7. Нажмите «Отправить в CRM». **Контакт принят только после ответа «Заявка сохранена».** Доставка происходит отдельно и не мешает следующей анкете.

«Главное меню» и `/start` сохраняют черновик. «Продолжить анкету» возвращает к вопросу. «Назад» возвращает предыдущий шаг; `/back` делает то же. «Отмена» или `/cancel` завершает черновик. Новый контакт при незаконченной анкете предлагает продолжить или явно начать заново. Черновик старше суток нужно подтвердить как актуальный.

«Мои заявки» показывает только ваши последние десять заявок:

- «В очереди» / «Проверяется» / «Ожидание повтора» — данные сохранены, доставка ещё идёт.
- «Создано в CRM» — карточка и комментарий, если он был, сверены.
- «Совпадение — у администратора» — контакт уже есть; бот не менял существующую карточку.
- «Нужна проверка администратора» / «Ошибка» — обратитесь к владельцу с номером заявки.

После отправки правки делаются через владельца. Не отправляйте анкету повторно только из-за задержки CRM. Старые кнопки могут быть недействительны: откройте `/start`. Фото, голосовые и файлы не распознаются; ответьте текстом. При выключенном сервере/VPN Telegram сохраняет ещё не полученные события до суток. Если ответа о сохранении нет, после восстановления проверьте черновик/«Мои заявки», затем введите контакт заново при необходимости.
